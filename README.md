# 🎯 Interview AI

An AI-powered mock interview platform that simulates technical interviews using Google's Gemini API. The application generates interview questions based on a selected role and experience level, conducts interactive interview sessions, evaluates responses, and provides AI-generated feedback to help users improve their interview performance.

---

## 🚀 Features

- 🤖 AI-generated interview questions
- 💬 Interactive mock interview sessions
- 🗣️ Speech-to-text support for answering questions
- 🔊 Text-to-speech for AI interviewer
- 📊 AI-powered feedback and performance evaluation
- 🔐 Secure user authentication
- 📁 Interview history dashboard
- 📱 Responsive and modern UI

## ⚡ Installation

Clone the repository

```bash
git clone https://github.com/your-username/interview-ai.git
```

Navigate to the project directory

```bash
cd interview-ai
```

Install dependencies

```bash
npm install
```

Create a `.env.local` file and add the required environment variables.

Run the development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```

## 📖 How It Works

1. User signs in securely.
2. Selects interview role and experience level.
3. Gemini AI generates interview questions.
4. User answers using voice or text.
5. AI evaluates responses.
6. Detailed feedback is stored for future review.
